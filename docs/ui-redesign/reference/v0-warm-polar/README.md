# v0 mock: "Warm polar" (visual reference only)

A one-page Next.js 16 / shadcn mock supplied on 29 Sep 2026 (`dhruv-frontend.zip`). It holds only
hard-coded fixture data. The two files are kept as `.txt` so no tool builds or lints them.

What `apps/web` took from it:
- the warm ivory and copper palette, darkened for WCAG AA (`docs/ui-redesign/CLAUDE.md` section 4);
- the top-bar brand block and the chrome-coloured top bar and sidebar;
- cards with a header bar;
- the Command layout: decision queue, network schematic, event stream, readiness table, decision callout and next resupply.

What it did not take, because it breaks section 11 of CLAUDE.md:
- uppercase tracked labels, text under 12 px;
- 14 px radius, shadows and hover lift, coloured left bars;
- pulsing and looping animation, the bottom status bar, the dark schematic panel;
- the mock's Next.js/shadcn stack and its fixture data.
