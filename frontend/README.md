# DHRUV Frontend

React + TypeScript + Vite frontend for DHRUV.

## Development

```bash
npm install
npm run dev
```

## Current scope

- App shell
- Command Center route and layout skeleton
- Decision Detail route
- Incident route
- What-if route
- Dark operations-room design tokens
- PWA foundation
- Zustand / Dexie dependencies ready for integration

The UI does not calculate operational values. Engine outputs will be rendered once the shared engine contract is wired in.
